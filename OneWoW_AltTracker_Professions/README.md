# OneWoW AltTracker: Professions

**Companion data store for [OneWoW_AltTracker](../OneWoW_AltTracker/README.md).** Collects profession skills, recipes, and cooldowns across your account. No standalone UI — data appears in AltTracker and other suite addons when enabled.

## Installation

Install alongside **OneWoW**, **OneWoW_AltTracker**, and the other OneWoW_AltTracker_* companion addons. Enable all load units via OneWoW → Manage Features.

## Requirements

- **OneWoW** — Core hub (required)
- **OneWoW_AltTracker** — Parent module (required)
