OneWoW Custom Overlay Icons
===========================

Drop your own overlay icon files into this folder and reference them by file
name from OneWoW > QoL > Overlays when choosing "Custom file" as an overlay
icon source.

Requirements
------------
* Supported formats: BLP, TGA, or PNG.
* Dimensions must be powers of two (e.g. 32x32, 64x64, 128x128).
  Square icons look best on item buttons.
* Use transparency (alpha channel) for anything outside the icon shape.

Important
---------
* World of Warcraft only picks up new files at a FULL CLIENT RESTART.
  A /reload is NOT enough — quit the game completely and start it again
  after adding or replacing files here.
* The game cannot list the files in this folder. Type the exact file name
  (including extension) in the overlay settings, e.g. "myicon.png".
* If the icon shows nothing in the preview, the file name is wrong, the
  format is unsupported, or the client has not been restarted yet.
