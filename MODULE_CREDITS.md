# Module credits

In-game credit for each QoL module is the `author` field in
`OneWoW_QoL/Modules/external/<id>/module.lua` (the Details dialog). If that
field is omitted or empty, credit is the OneWoW Development Team.

This file lists **community** modules. Giving a module to OneWoW is not
exclusive ownership. The OneWoW Development Team may change, modify, or
edit the shipped copy at any time (see [LICENSE.md](LICENSE.md)).

**License:** the author names the terms (a `LICENSE` file in that module
folder, recorded here). If License is empty, the submission is a
contribution to the OneWoW Development Team and that copy is OneWoW
codebase.

**Credit:** `Author` while the shipped module is still that person's work
(including our edits). After a complete rewrite, set Details `author` to
the OneWoW Development Team and set Credit here to `Concept`.
