# OneWoW - Data: Quest Archive

**Classic through Dragonflight quests for the OneWoW Catalog.** The current expansion and the previous one stay in **OneWoW_CatalogData_Quests**. This pack loads when you browse older expansions, search all quests, or look up quest rewards.

Players use it through Catalog. There is no standalone UI and no SavedVariables.

## Required Addons

- **OneWoW** - Core hub (required)
- **OneWoW_CatalogData_Quests** - Hot quest pack (loaded first when Archive is needed)
