**OneWoW Notes** is a searchable notebook for players, NPCs, zones, items, and free-form journals — with pins, hyperlinks, and account- or character-scoped storage.

**Requires:** [OneWoW](Home) core. Enable **Notes** under [Manage Features](Getting-Started).

**Open:** `/1wn` · `/own` · `/onewownotes` (see [Slash commands](Slash-Commands))

---

## Tabs (overview)

| Tab | Use it for |
|-----|------------|
| **Notes** | General journal — categories, tags, todos, favorites, login notes, pin-to-screen, rich text |
| **Players** | Guildmates and friends — realm, guild, class, personal comments |
| **NPCs** | Vendors and important NPCs — location, stock, quests |
| **Zones** | Map pins and zone tips — quest hubs, rares, farming spots |
| **Items** | Item sources, farming routes, rewards — link items and search notes about them |

---

## Handy features

* Hyperlinks to items, spells, NPCs, quests, and achievements; cross-links between notes
* Coordinates and waypoints you can navigate to
* Account-wide or per-character storage
* Right-click helpers (target info, timestamps, character name)
* Auto-save as you type
* Suite themes and all eleven locales via OneWoW

QoL **Inspect Gear** can save inspect notes into Notes when that module is enabled.

---

## Tips

* Use account storage for guild/raid knowledge you want on every alt; character storage for private alts-only notes.
* Pin a short checklist note while doing a long questline.
