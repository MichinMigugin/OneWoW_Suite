# Getting started

After [Install](Install), this is the shortest path to a working setup.

## Open the hub

In-game, type:

* `/ow` · `/1w` · `/one` · `/onewow`

That opens the OneWoW hub — portals, settings, and tabs for enabled features.

## First-run wizard

On a fresh install, OneWoW may open a setup wizard. You can reopen it later with `/ow-wizard` if you want to revisit those choices.

## Manage Features

In the hub, open **Manage Features**:

* Enable only the modules you use (Bags, QoL, AltTracker, Catalog, and so on)
* Disabled modules are unloaded, not merely hidden
* Some features ship with companion data folders (for example Catalog or AltTracker data stores) — enable the parent feature; the companions load with it

## Themes and locales

The suite shares themes across addons and supports all eleven client locales. Configure appearance from the hub settings; in-game text follows your WoW language.
